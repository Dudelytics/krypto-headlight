# Dudelytics Krypto-Headlight
**Die Wochenlage des produktiven Kryptomarkts.**

Öffentliche, kostenlose Wochenberichte von Dudelytics. Herausgeber: Axel Lämmle / Dudelytics.

## Websites
- Dudelytics: https://dudelytics.com/
- Krypto-Headlight (aktuell veröffentlicht): https://dudelytics.github.io/krypto-headlight/
- Research Hub: https://dudelytics.com/research/

Die Dudelytics-Hauptdomain bleibt bei STRATO. Eine spätere Headlight-Subdomain wird erst nach vollständiger Domain- und HTTPS-Prüfung als kanonische Adresse aktiviert. Das optionale GitHub-Repository-Feld „Website“ kann auf die Headlight-Adresse zeigen; es steuert nicht die GitHub-Pages-Domain.

## Redaktion
Die öffentliche Website liegt in `docs/`. Freigegebene Ausgaben werden als Markdown-Dateien in `docs/_posts/YYYY-MM-DD-krypto-headlight.md` veröffentlicht. GitHub Pages baut die Seite aus `main /docs`.

Entwürfe werden Axel zunächst im Chat zur Freigabe vorgelegt. Ungeprüfte Entwürfe gehören nicht auf die öffentliche Website. Erst nach Freigabe wird eine Ausgabe mit Quellen und überprüftem Datenstand committed.

Siehe [Redaktionsregeln](REDAKTION.md) und [Ausgabenvorlage](VORLAGE.md).

Kommentare laufen über die [GitHub Discussions](https://github.com/Dudelytics/krypto-headlight/discussions). Lesen ohne Anmeldung, kommentieren mit GitHub-Konto. Für jede Ausgabe wird eine eigene Diskussion angelegt und als `discussion_url` verlinkt.

## Betrieb und Rollback
GitHub Pages benötigt keinen STRATO-Dateiupload für neue Ausgaben. STRATO wird nur für Domain und Verlinkung benötigt. Eine fehlerhafte Veröffentlichung wird durch einen nachvollziehbaren Korrekturcommit zurückgenommen; publizierte Aussagen werden nicht stillschweigend verändert. Rücknahme einzelner Ausgaben: Hinweis statt unkommentierter Löschung.
