# Freiwillige Lesestatistik

Die zusätzliche Lesestatistik ist derzeit nicht aktiviert. Es werden dafür keine Daten an Umami übertragen.

Vor Aktivierung werden hier Anbieter, Hostingregion, verarbeitete Daten, Speicherdauer, Einwilligung und Widerruf beschrieben. Die bestehende [Datenschutzerklärung](https://dudelytics.com/datenschutz/) und die Verarbeitung technisch notwendiger Hostingdaten bleiben hiervon getrennt.
