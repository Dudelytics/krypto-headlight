Save as `docs/en/_posts/YYYY-MM-DD-crypto-headlight.md` with:

```yaml
---
layout: post
lang: en
permalink: /en/editions/YYYY-MM-DD/
translation_key: "YYYY-MM-DD"
translation_url: /ausgaben/YYYY-MM-DD/
title: "[English title]"
description: "[English summary]"
date: YYYY-MM-DD HH:MM:SS +0100
discussion_url: "[Same verified discussion as the German edition]"
---
```

Set `lang: de`, the same `translation_key`, and the reciprocal English `translation_url` in the German post. Each language's homepage, archive and feed select only that language. The latest published edition is displayed immediately. Earlier German-only issues remain in the German archive.

Use the same section sequence, evidence, source timestamps and corrections as the German edition. Figures require English alternative text, captions and explicit dimensions. Tables require captions and row/column scopes. The quiet source-notes block stays at the end.

For email, use the separate English signup, opt-in template and confirmed English recipient list. Prepare each mailing from the approved English edition.
